# Lucy: automated job-search assistant

Lucy asks college students a few quick questions and matches them to real entry-level jobs and internships from public company job boards (Greenhouse and Lever).

- `index.html`: the chatbot (one page, no build step)
- `jobs.json`: the job listings, refreshed daily
- `Code.gs`: Google Apps Script that writes consented interaction logs to the team's private Google Sheet

Lucy is a bot. It can't apply for you or promise a job. It never asks for or uses name, gender, race, ethnicity, age, religion, or disability.
